# cpu-scheduler-simulator

## Overview

A C++ CPU scheduling simulator implementing the First Come First Served (FCFS) scheduling algorithm. The program calculates key scheduling metrics including Waiting Time (WT), Turnaround Time (TAT), and average statistics for a set of processes.

## Features

* Process creation and storage
* FCFS scheduling
* Waiting Time calculation
* Turnaround Time calculation
* Average WT and TAT calculation
* Gantt chart visualization
